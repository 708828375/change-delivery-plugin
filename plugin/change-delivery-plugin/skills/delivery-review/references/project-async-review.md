# ExampleProject 异步任务专项 Review

仅在变更触及对应链路时应用以下判据。

- **Outbox/Celery**：payload 与 task 参数兼容；派发崩溃窗口不会造成重复数据、重复扣费或永久阻塞。
- **幂等**：幂等键表达稳定业务身份或真实处理轮次；成功落库与 item 终态之间存在带状态、锁归属守卫的补偿路径。
- **并发**：并发 worker 不共享 `AsyncSession`；状态更新检查当前状态、软删条件和锁归属。
- **恢复**：Watchdog、锁过期与心跳续租受业务绝对超时约束，可恢复任务不依赖人工重新启动。
- **扣费**：成功 item 重跑不重复扣费，扣费后失败可由稳定证据识别并补偿。
- **实时状态**：WebSocket 快照、订阅和重连之间不静默漏失关键状态，畸形消息和慢消费者不拖垮共享资源。
- **大表查询**：依据真实 `WHERE`、`ORDER BY`、`GROUP BY`、`LIMIT` 核对迁移中的索引，而不是只看 ORM 声明。

# ExampleProject 功能验收补充规则

仅在运行主机提供相应只读探针事实时使用本文件。

- 优先从 public API、前端入口或批准的 WebSocket 探针验证用户可见行为；每个场景记录前置状态、操作、确定性断言、等待上限和资源 ID。
- API 接受、`X-Request-ID` 或任务入队只证明链路开始，不能替代任务终态、业务结果或真实接收端证据。
- Docker 日志、容器状态、Outbox、worker、WebSocket 和只读 SQL 只作关联旁证；Skill 不自行建立 SSH 或数据库连接。
- 测试数据通过批准的 public API 创建。确需 DB setup 时返回 blocked，等待流程外单独授权。
- 真实外部系统只断言可重复且有权威证据的部分，不发送真实邮件、不支付、不调用生产计费服务。

报告需区分通过、失败、阻塞、未覆盖、清理结果和残留风险。SHA 不确定或资源未安全清理时不能通过。

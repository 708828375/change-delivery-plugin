# ExampleProject 验收检查清单

## 身份与连续性

- 记录 run ID、准确运行前缀 `codex-<run-id>` 和预期 40 字符 SHA。
- 通过已登记适配器读取远程测试分支，通过版本端点读取配置的 SHA 字段；开始、关键场景前和结束时两者都应等于预期 SHA。
- 任一来源漂移即返回 `ENVIRONMENT_PREEMPTED`，后续结果不能归因于本次变更。

## 资源台账

- 临时写操作只使用批准的 public API，并为对象附加准确运行前缀。
- 每次创建后记录资源类型、准确资源 ID、父 ID、返回标记和创建结果；不从名称、列表位置或时间推断 ID。
- 外部依赖与不可逆动作遵守批准方案；不发送真实邮件、执行真实付款或调用昂贵生产模型。

## 断言与清理

- 断言面向业务终态；异步轮询有明确上限。日志与数据库只作只读旁证。
- 清理仅处理本次资源台账中的准确 ID：先子后父，删除前核对运行标记，删除后验证准确 ID 不存在。
- 所有权不匹配或清理失败时停止，记录剩余 ID、影响和所需后续授权；不做通配符、时间窗口、账户级清理或数据库直写。

## 验收证据

报告包含开始/结束 SHA、场景断言、资源 ID、清理结果、失败或未覆盖项，并对凭据、cookie、消息正文和个人数据脱敏。

# 项目补充验证清单

此清单用于判断运行主机的权威验证事实是否覆盖当前变更，不负责替代或执行 `required_pre_pr_checks`。

## 覆盖范围

- 先核对与改动直接相关的聚焦验证，再判断共享组件、公共 DTO、权限、事务、缓存、队列、配置和序列化是否需要扩大覆盖。
- 行为修改应包含成功路径、失败路径和关键边界；修复应有能够复现原问题的测试或可审计替代证据。
- 涉及批量处理时，检查空集合、单条、典型批量规模、分页边界和部分失败；关注 N+1、重复远程调用和资源上限。
- 涉及异步任务时，检查 payload 契约、幂等、锁归属、重试、终态和部分成功恢复。

## 结论要求

- 只引用实际提供的命令、退出码、准确 SHA 和只读事实，不得把计划执行、历史通过或口头说明当作本次通过。
- 对未运行的全量测试、环境限制、依赖缺失和无法自动化的场景列出未覆盖项及其风险。
- 权威检查失败时必须保持失败；补充检查只能收紧，不能把失败改写为通过。

# 项目补充验证清单

用它判断运行主机的 `required_pre_pr_checks` 是否覆盖本次风险，不替换权威命令。

- 行为变更应覆盖成功、失败和关键边界；缺陷修复应有能复现原问题的测试或等价可审计证据。
- 共享 DTO、权限、事务、缓存、队列、配置或序列化变化，需要覆盖受影响的上下游。
- 批量处理关注空集合、分页边界、部分失败、N+1 和资源上限；异步任务关注 payload、幂等、锁、重试、终态与恢复。
- 证据绑定当前 SHA，并包含命令、退出码和关键输出。历史通过、计划执行或口头说明不算本次结果。

权威检查失败时保持失败；环境限制、依赖缺失和未运行项作为风险明确列出。

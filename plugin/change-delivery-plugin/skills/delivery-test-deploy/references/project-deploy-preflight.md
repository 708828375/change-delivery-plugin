# ExampleProject 测试部署预检

本检查只读，不拥有推送或部署权限。

## 身份检查

- 核对项目 ID、remote、测试分支、push 策略和预期 SHA 均来自同一份已登记配置。
- 核对预期 SHA 是本次已验证和已 Review 的准确提交，不接受分支名称代替 SHA。
- 核对版本端点及 SHA 字段已登记且使用 HTTPS；凭据只允许通过运行主机批准的环境变量名称引用。

## 部署前风险

- 如果当前共享测试环境存在另一个运行占用、配置事实不完整或远端身份不一致，返回 `blocked`。
- 不连接个人路径中的密钥，不猜测服务器、容器或数据库地址，不通过 Skill 修改环境。
- 预检通过只表示允许运行主机继续；实际推送、部署轮询和远端 SHA 复核仍由运行主机执行。

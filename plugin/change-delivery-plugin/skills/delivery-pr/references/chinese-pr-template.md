# 中文 PR 模板

## 标题

使用以下格式：

```text
<type>(<影响范围>)：<中文简短说明>
```

`type` 使用常见 Conventional Commits 类型；中文语境使用全角冒号。标题必须概括实际变更，不声称尚未完成的结果。

## 正文结构

根据当前变更保留有内容的章节：

```markdown
## 变更说明

## 背景与方案

## 改动范围

## 测试情况

## 影响范围

## 部署注意事项

## 风险与未覆盖项

## 关联信息
```

- 变更说明描述用户可感知结果，不机械罗列文件。
- 测试情况只列运行主机提供的命令和权威结果；没有执行的项目明确标为未执行。
- 部署注意事项记录配置、迁移、兼容和回滚要求，没有则写“无”。
- 关联 Issue、任务和文档必须来自已批准产物或运行主机事实，不得猜测。
- 只有存在权威证据的检查项才能标记完成；Draft PR 不能声称已经合并或上线。

# 阶段 Skill 可定制自动交付 MVP 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `subagent-driven-development`（推荐）或 `executing-plans` 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法跟踪进度。用户已明确要求直接在当前仓库开发，不创建独立 worktree。

**目标：** 保留固定交付状态机，为每个业务阶段提供可编辑 Skill，并让方案批准后的状态自动连续推进到人工关卡、阻塞状态或 `READY_TO_MERGE`。

**架构：** 继续以 `Orchestrator.step()` 作为唯一单步状态权威，在其外增加有上限的连续推进循环。Skill 负责阶段内容和受限建议；运行主机继续校验 Schema、执行 Git/PR/测试环境副作用、绑定 SHA 和登记证据。内部 Review 使用新增固定状态形成“Review -> 修复 -> 本地验证 -> 再 Review”闭环；commit 和 PR 使用专用结构化内容契约，不让 Skill 直接写 Git 或调用 GitHub。

**技术栈：** Python 3.12、Pydantic 2、JSON Schema Draft 2020-12、SQLite、Codex CLI、PowerShell、pytest。
